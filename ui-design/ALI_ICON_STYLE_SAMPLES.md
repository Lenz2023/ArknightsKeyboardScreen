# Alibaba-style icon comparisons

These concept previews keep the same weather screen and show three different visual directions for both forecast and life-guide icons:

- D — colorful flat illustration, referencing iconfont's multicolor icon style.
- E — soft 3D object style, referencing iconfont's 3D illustration category.
- F — hand-drawn sticker style with a bold outline and pale sticker edge.

The renderings are comparison sketches for the 320 × 240 display, not downloaded iconfont artwork. iconfont supports downloading SVG and PNG assets; the weather collection reference is [here](https://www.iconfont.cn/collections/detail?cid=51731). Individual iconfont assets are uploaded by different creators, so check each asset's displayed license before bundling it.

Run `Generate-IconStyleSamples.ps1` to regenerate the board and individual previews.
