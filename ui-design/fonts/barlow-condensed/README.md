# Barlow Condensed for the Heavy Rain UI

- Typeface: Barlow Condensed SemiBold Italic, Latin glyph subset.
- Source: Google Fonts / `@fontsource/barlow-condensed` 5.3.0.
- License: SIL Open Font License 1.1 (`LICENSE`).
- Embedded LVGL builds: 16 px and 32 px, 4 bpp, generated with `lv_font_conv`.
- The weather and city labels remain in the existing Chinese font.
