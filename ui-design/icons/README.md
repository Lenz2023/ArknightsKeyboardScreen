# Weather screen icons

The shirt, dumbbell, pill, car-front, cloud-sun, and cloud SVGs are Lucide icons, with their SVG geometry kept at Lucide's 24 × 24 viewBox. The small-screen preview and RGB565 background use GDI+ paths translated from these same Lucide outlines so the icons can be drawn into the firmware background without an SVG decoder.

Source files: [shirt](https://lucide.dev/icons/shirt), [dumbbell](https://lucide.dev/icons/dumbbell), [pill](https://lucide.dev/icons/pill), [car-front](https://lucide.dev/icons/car-front), [cloud-sun](https://lucide.dev/icons/cloud-sun), and [cloud](https://lucide.dev/icons/cloud).

The icons come from [Lucide](https://github.com/lucide-icons/lucide) and are distributed under the ISC license; see [LICENSE](LICENSE).

The project design preview is generated by `../Generate-WeatherDesign.ps1`.
