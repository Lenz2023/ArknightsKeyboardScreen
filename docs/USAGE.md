## 1. 按键速查

| 操作 | 作用 |
| --- | --- |
| `Fn + ~` | 切换到下一个页面 |
| **长按** `Fn + Menu` | 进入 / 退出设置页 |

页面切换顺序（登录状态下）：

```
首页 → 天气 → 音乐 → 博士档案 → 每日数据 → 卫戍协议 → 首页 …
```

没登录森空岛时，「博士档案」位置会变成「森空岛登录页」；
长按 `Fn + Menu` 可以随时插进设置页再返回。

## 2. 第一次开机：配网

刚烧完固件、或换过 WiFi 时，开机后会自动进入**配网页**。

1. 屏幕会提示已开热点，用手机 WiFi 列表连上名字类似 `skyloong-…` 的热点（无密码）
2. 连上后手机会自动弹出配置页；没弹出就手动打开浏览器访问 `192.168.4.1`
3. 选你家 WiFi、填密码、保存
4. 设备连上后自动退出配网页，回到正常页面

> 如果 WiFi 密码输错了：长按 `Fn + Menu` → 设置 → **重选 WiFi** → 重新走一遍上面的流程。

## 3. 森空岛扫码登录

1. `Fn + ~` 切到 **森空岛登录** 页，屏幕会自动出现一个白底二维码
2. 打开手机上的**森空岛 App** → 右上角扫码
3. 手机上确认登录
4. 屏幕提示「已登录森空岛」后会自动跳到**博士档案**页，开始拉数据

几点说明：

- 二维码过期会自动刷新，不用手动操作
- 登录状态会保存，**断电重启也不用重新扫码**
- 登录凭证过一段时间会过期，固件会自动用保存的账号 token 续期
- 想换账号：设置 → **重新登录森空岛**

## 4. 日常使用

开机后默认停在你在设置里选的「开机首页」（默认卫戍协议）。

- **博士档案页**：3 分钟自动刷新一次；显示不出来时等 30 秒会自动重试
- **每日数据页**：在博士档案页再按一次 `Fn + ~` 进入，理智/无人机满了会变柠檬绿
- **卫戍协议页**：战绩看板与称号看板每 9 秒自动交替
- **天气页**：数据由后台定时刷新，切进去立刻就有内容
- **音乐页**：需要电脑端插件把网易云「正在播放」推过来，见 [4.1](#41-音乐页与歌词同步可选)

网络断了会显示上次缓存的快照并标注「已载入缓存」，恢复后自动更新。

### 4.1 音乐页与歌词同步（可选）

音乐页自己**不联网**，它显示的是电脑端推过来的播放状态。所以要让它有东西，必须先装一个电脑端小插件（BetterNCM 插件 `GK4ScreenMusicBridge`）。

#### 需要准备什么

| 项目 | 说明 |
| --- | --- |
| 网易云音乐 PC 版 | Windows 上的网易云客户端（插件跟着它跑，没有独立窗口） |
| [BetterNCM](https://github.com/BetterNCM/BetterNCM) | 网易云插件运行环境 |
| 插件 `LibEAPIRequest` | BetterNCM 商店里装，负责发网易云的加密请求 |
| 插件 `LibLyric` | BetterNCM 商店里装，负责取歌词 |
| 网络 | 电脑和键盘在**同一个 Wi-Fi**；键盘已配网、屏幕停在主界面 |

> 少了后两个也能用：歌名、歌手、进度照样显示，只是没有同步歌词。

#### 第一步：装插件

**插件商店装**（等商店收录后可用）：BetterNCM 插件商店里搜 `GK4ScreenMusicBridge` → 安装。

**手动装**（现在就能用）：

1. 拿仓库里的 [`pc-companion/GK4ScreenMusicBridge.plugin`](../pc-companion/GK4ScreenMusicBridge.plugin)
2. 在 BetterNCM 面板里点 **Open Folder** 打开插件目录，把 `.plugin` 文件丢进去
3. 在 BetterNCM 里重载插件，或直接重启网易云

装完在插件列表里确认 **LibEAPIRequest** 和 **LibLyric** 都处于启用状态。

#### 第二步：告诉插件屏幕在哪

插件默认用 mDNS 名字 `http://skyloong-screen.local`。Windows 上多数情况能解析；解析不了就填 IP：

1. 键盘进 **设置 → 启动 Web 服务器**，屏幕上会显示访问地址，形如 `http://192.168.1.20`
2. 在 BetterNCM 插件列表里点 `GK4ScreenMusicBridge` 的 **设置** 按钮
3. 把地址填进输入框 → **保存并测试** → 看到「已连接：http://…」就成了

不想手抄 IP 就点 **自动发现**：插件会先试 mDNS 名，再用 WebRTC 拿到本机网段，按 /24 分段扫一遍局域网找屏幕。填错了点 **清除记录** 回到默认。

> 地址会记在浏览器的 `localStorage`（键名 `gk4-screen-base-url`），下次开网易云不用重填。

#### 第三步：验证

播放任意一首歌，应该发生这些事：

- 键盘屏幕**自动切到音乐页**（不用按 `Fn + ~`）
- 屏幕显示：`NOW PLAYING` + 歌名 + 歌手 + 当前歌词（大字）+ 下一句（暗色小字）+ 底部进度条
- 暂停 → 停在音乐页，曲目信息保留
- 关掉/退出网易云 → 屏幕退回原来的页面

#### 命令行自测（不想开网易云时用）

确认屏幕地址后，随便找台同网段的电脑：

```bash
curl -X POST "http://192.168.1.20/music" \
  -H "Content-Type: text/plain;charset=UTF-8" \
  -d '{"active":true,"playing":true,"title":"测试曲目","artist":"测试歌手","lyric":"这是当前歌词","next":"这是下一句歌词","position_ms":45000,"duration_ms":180000}'
```

返回 `OK` 且屏幕跳到音乐页 = 设备端正常，问题在插件侧。

#### 这一节的问题排查

| 现象 | 原因 / 处理 |
| --- | --- |
| 屏幕一直停在别的页，音乐页空白 | 插件没装或没启用；网易云没在播放；去插件设置里点「保存并测试」看是否「已连接」 |
| 只有歌名，没有歌词 | `LibLyric` / `LibEAPIRequest` 没启用，或这首歌本来就没有同步歌词（屏幕会显示 `♪ 暂无同步歌词`） |
| 插件设置里「连不上」 | 电脑和键盘不在同一 Wi-Fi；键盘休眠了（按一下键唤醒）；IP 填错 |
| 屏幕没自动切页，但播放正常 | 检查固件版本；老固件需要手动按 `Fn + ~` 切到音乐页 |
| 歌词比音乐慢半拍/快半拍 | 插件侧固定 400 ms 提前量（`LYRIC_LEAD_MS`），如需微调见插件说明 |

更详细的插件行为与源码说明见 [`pc-companion/README_zh.md`](../pc-companion/README_zh.md)。

## 5. 设置页怎么用

**长按 `Fn + Menu`** 进入：

| 项目 | 说明 |
| --- | --- |
| 开机首页 | 选下次开机落在哪一页 |
| 自动关机 | 多久没按键就熄屏（省电，也保护屏幕） |
| 重新登录森空岛 | 清掉凭证重新扫码 |
| 重选 WiFi | 进配网页换网络 |
| 12 小时制 | 时间显示成 `14:05` 还是 `02:05 PM` |
| 启动 Web 服务器 | 启动后屏幕显示 IP，可访问图库页面 |

再长按一次 `Fn + Menu` 退回进入设置前的页面。

> 设置项改动会立刻写进设备的 NVS，断电不丢。

## 6. 换背景 / 换主页立绘（Web 图库）

背景是**按时间与天气自动切换**的（6 种画面：晴 / 多云 / 雨 / 雪 / 黄昏 / 夜）。
你可以只替换其中某一张，其余继续用官方场景。

### 6.1 打开图库页面

1. 长按 `Fn + Menu` → 设置 → **启动 Web 服务器**
2. 屏幕上会显示设备 IP，例如 `192.168.1.23`
3. 电脑连同一个 WiFi，浏览器打开 `http://192.168.1.23/art`

> 打不开时：确认电脑和设备在同一网段；公司/校园网常隔离设备，建议用手机热点。

### 6.2 传一张背景

1. 找到对应槽位的卡片（晴朗 / 多云 / 雨天 / 降雪 / 黄昏 / 夜景）
2. 点「选择文件」挑一张图
3. 在预览框里**拖动**调整位置、拖**缩放滑杆**放大缩小
4. 点「上传」

上传后立刻生效，**不用重启**，也不用切页。

要点：

- 裁切在浏览器里完成，导出尺寸精确为 320×240，设备只负责解码存储
- 只覆盖你上传的那个槽位；点「恢复默认」即删掉该槽位自定义图
- 想验证效果，右键预览图或刷新 `/art/preview?name=home-screen` 看主界面合成图

### 6.3 换主页左侧立绘

1. 最右边一张卡片是「主页立绘」
2. 上传任意带透明通道的 PNG（干员立绘、Q 版都行）
3. 用下面三个滑杆调 **水平位置 / 垂直位置 / 大小**，点「应用位置」
4. 页面上的预览会立刻更新

透明区域会保留，不会出现黑底。

## 7. 自动关机与省电

- 设置里的「自动关机」控制无按键多久熄屏，可选 1 / 3 / 5 / 10 / 30 分钟等
- 熄屏后**按任意键或打字即唤醒**，数据会继续刷新（不会因为熄屏丢登录）
- 屏幕常亮会一直耗电，桌面使用时建议设 5–10 分钟

## 8. 常见问题

### 屏幕全黑 / 没有任何内容
- 先按任意键唤醒（可能触发了自动关机）
- 长按 `Fn + Menu` 看能否进设置页；能进说明只是停在了没数据的页面
- 还是黑的：重新烧录（见 [FLASHING.md](FLASHING.md)）

### 卡在某个页面，按 Fn+~ 不响应
新版固件所有页面都不再阻塞切页。如果仍卡住，多半是旧固件，请重新烧录最新版。

### 博士档案页显示「博士数据同步失败」/ 卫戍页显示「赛季未同步」
- 森空岛接口偶发抽风，通常 10–30 秒自动恢复
- 一直不好：设置 → 重新登录森空岛，扫一次码
- 卫戍页「赛季未同步」也可能表示当前赛季还没开放战绩接口

### 卫戍页看不到难度 / 击杀 / 模式
接口本身只返回 `completeState`、`trophyAfter`、`passRound` 三个字段，
这些信息拿不到，页面会降级显示（详见 [FEATURES.md](FEATURES.md#5-卫戍协议页)）。

### 登录页看不到二维码
旧版本有 bug（二维码被背景层盖住），已修。请烧录最新固件。

### 音乐页一直是空的 / 不显示歌词
音乐页不自己联网，靠电脑端 BetterNCM 插件推送，所以先看这三件事：
- 插件 `GK4ScreenMusicBridge` 装了并启用了吗（BetterNCM 插件列表里能看到）
- 插件设置里点「保存并测试」，是不是显示「已连接」
- 网易云真的在播歌吗（暂停时只保留曲目信息，停止后屏幕会退回上页）

只有歌名没有歌词，多半是 `LibLyric` / `LibEAPIRequest` 没启用，或者这首歌没有同步歌词（此时屏幕显示 `♪ 暂无同步歌词`）。
完整步骤见 [4.1 音乐页与歌词同步](#41-音乐页与歌词同步可选)。

### 图库网页打不开
- 设置里确认「启动 Web 服务器」已开启，屏幕上要能看到 IP
- 电脑和设备必须在同一网段（校园网/公司网通常不行，用手机热点最稳）
- 换个浏览器试试（需要支持 canvas 的现代浏览器）

### 上传的图显示成黑块
旧版本问题，已修（透明通道现在完整保留）。更新固件即可。

### 时间不对
设备靠 NTP 校时。配网成功后自动对时；设置页里保存 WiFi 时也会触发一次校时。
时区默认东八区，可在 Web 配置页 `/` 里调整。

### 刷完固件后设置都没了 / 换了一块新键盘

用仓库里那四个分片镜像刷（网页刷机或 `flash-noidf` 脚本）**不会动设置**，WiFi、森空岛登录、
自定义背景都会留着。设置被清空通常只有三种情况：

1. 烧录时手选了 **Erase device**（整片擦除）；
2. 用了旧的「合并单文件」镜像（它会把 NVS 填成 0xFF，已从仓库移除）；
3. 这是一块新板子 / 第一次刷本固件。

恢复只要三步，约两分钟：

1. **配网**：屏幕若停在配网二维码页，用手机连热点 `SKYLOONG 4.0 Screen`，浏览器会自动弹出配置页
   （没有的话手输 `192.168.4.1`），选家里的 WiFi 并填密码；
2. **校时**：联网后设备会自动 NTP 对时，不用管；
3. **登录森空岛**：长按 `Fn + Menu` 进设置 → 点「重新登录森空岛」→ 用森空岛 App 扫码。

登录成功后回到博士档案页，数据会自己出现；刷不出数据就等 10–30 秒，或再按一次 `Fn + ~` 重进该页。
