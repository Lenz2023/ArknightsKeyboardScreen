键盘实拍（照片做过调色处理；屏幕内容与真机一致）

这是什么

  • 键盘小屏上显示明日方舟：博士档案、每日/每周任务、卫戍协议战绩与赛季称号
  • 还有天气、网易云歌词、系统设置、森空岛扫码登录
  • 背景按时间 + 天气自动切换，素材取自游戏内「首页场景」，也可自己上传替换
  • 配套一个网页图库，浏览器里裁好 320×240 直接传到设备

文档

  • 使用教程：按键操作、配网、扫码登录、图库

  • 烧录指南：三种刷机方式与常见报错
  • 硬件说明（PDF）：引脚表、接口原理图与时序，二次开发用
