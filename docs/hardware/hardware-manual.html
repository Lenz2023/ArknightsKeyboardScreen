一、系统概述

依据：sdkconfig、main/hal.cpp 的 HAL::init()

副屏模块是一块独立的 ESP32-S3 小板。它通过 UART 接收键盘主控送来的按键、电量和状态， 接管键盘自带的 320×240 屏幕，并负责联网（Wi-Fi）、显示和出声。整机由键盘的 USB-C 供电。

部件型号 / 规格说明
主控ESP32-S3（QFN56，芯片 rev v0.2）双核 Xtensa LX7 @240 MHz，内置 Wi-Fi / BLE
Flash16 MB（片外）双 OTA 各 5 MB，另有约 5.8 MB 数据分区
PSRAM8 MB（AP_3v3）立绘解码、图像缓存、音频数据
晶振40 MHz主时钟
显示屏ST7789 · 240×320 原生 · IPS8 位 8080 并口；setRotation(3) 后为 320×240，BGR 顺序，软件反色
音频编解码ES8311（I2C 从机 0x18）I2C 配置 + I2S 数据，外接功放（GPIO10 使能）
实时时钟DS1302三线串行（SCLK / SDIO / CE），走时靠纽扣电池
键盘通信UART1 · 115200 8N1自定义帧：STX / LEN / TYPE / DATA / ETX / CRC
USBESP32-S3 原生 USB-Serial-JTAG无外置转串口芯片；同时枚举日志口与烧录口
图 1　系统连接框图
职责边界：按键矩阵、旋钮、电量采集、休眠判定都在键盘主控侧，副屏不直接扫描按键； 主控把事件打包成 UART 帧推过来，副屏只做“显示 + 联网 + 出声”。

三、显示接口

依据：main/hal.cpp 的 lcd_init() 与 HAL::setBrightness()、components/TFT_eSPI/User_Setup.h

屏幕走 8080 并口（8 位）而不是 SPI。原因很直接：一帧 320×240×16bit 是 150 KB， 并口每个写周期送一个字节，整屏刷新比 SPI 快一个量级，切页和滚动才不糊。

图 2　并口显示接口：8 根数据线 + 5 根控制线

3.1 写时序

  • 写命令：CS=L, DC=0 → 数据放 D0–D7 → WR 拉低再拉高（上升沿锁存）。
  • 写数据：CS=L, DC=1，时序同上。
  • 并口模式 不能用 DMA（TFT_eSPI 会给出 DMA is not supported in parallel mode 的编译提示）， 刷新靠 CPU 直写；所以界面逻辑尽量只重绘变化区域。

3.2 初始化顺序（lcd_init()）

  1. pinMode(PIN_DISPLAY_PWR, OUTPUT) → digitalWrite(..., LOW)：给屏上电（低有效）。
  2. ledcAttach(PIN_DISPLAY_BL, 16000, 8)：背光 PWM 16 kHz / 8 位，初始占空比 0（全暗）。
  3. delay(1000)：等面板电源稳定。
  4. tft.init() → tft.setRotation(3)（转成 320×240 横屏）→ 清屏 → tft.invertDisplay(true)。

3.3 亮度

亮度是 0–9 档，直接映射成 PWM 占空比；熄屏时写 0。注意 0 档不是全黑（占空比 10）， 真正的“关屏”是熄屏逻辑把占空比写成 0。

档位0123456789
占空比10152030406090130180255

四、音频接口

依据：main/hal.cpp 的 HAL::audio_init() / HAL::setVolume()、main/include/A_Config.h

链路是 ESP32-S3 → ES8311（DAC）→ 功放 → 喇叭。ESP32-S3 用 I2S 送 PCM，用另一路 I2C 配置编解码器； 功放使能单独一根 GPIO，音量归零时一起拉低，避免底噪。

图 3　音频信号链

4.1 初始化顺序（HAL::audio_init()）

  1. pinMode(AUDIO_AMP_CTRL, OUTPUT) 并 先拉低——功放保持静音，避免上电爆音。
  2. Wire.begin(12, 13)；es8311_create(I2C_NUM_0, ES8311_ADDRRES_0)。
  3. es8311_init(handle, &es_clk, ES8311_RESOLUTION_16, ES8311_RESOLUTION_16)：16 bit 采样。
  4. es8311_microphone_config(handle, false)：关闭麦克风通路。
  5. es8311_voice_volume_set(handle, 0, NULL)：先把音量归零。
  6. 建 I2S 通道：I2S_NUM_0 主机、标准模式、44.1 kHz、16 bit、双声道、MCLK 256 倍频，然后 i2s_channel_enable()。
  7. 启动时读存档音量并 setVolume()；默认 0（静音）。

4.2 音量控制（HAL::setVolume()）

音量 0–9 档，查表换算成 ES8311 的 0–100 数字量写入寄存器；同时按档位开关功放使能脚。

档位0123456789
寄存器值0384653596468717374
功放低高高高高高高高高高
默认音量是 0，此时功放使能脚为低、播放任务空转不解码。所以“没有声音”先看设置页的音量滑杆， 而不是怀疑硬件。

五、RTC 接口（DS1302）

依据：main/hal.cpp 的 HAL::init()（DS1302_begin 调用处）

DS1302 是经典三线串行 RTC，接在三个普通 GPIO 上。初始化时固件会传入引脚号并写一次涓流充电寄存器 （DS1302_writeClockRegister(&rtc, DS1302_REG_TC, 0xA5)）；联网后由 NTP 校时，校时结果再写回 RTC。

信号GPIO说明
SCLK9时钟，MCU 输出
SDIO11数据，双向（读时间 / 写时间）
CE / RST0片选，一次读写开始时拉高
走时依赖模块背面的纽扣电池（VBAT）。电池没电时开机时间会退回默认值，联上网后靠 NTP 校正。

六、键盘通信接口（UART1）

依据：main/protocol.cpp（帧结构、CRC、消息类型）与 main/include/A_Config.h（引脚）

副屏与键盘主控之间只有两根线：GPIO17 收、GPIO1 发，115200 8N1。 帧结构是自定义的，带帧头、长度、类型与异或 CRC。

6.1 MENU(0xA3) 的子命令

子命令行为
0xA0进 / 退编辑模式（右下两个键同时长按），进入时切到设置页
0xA1Backspace
0xA2 / 0xA3 / 0xA4 / 0xA5方向键 左 / 右 / 上 / 下
0xAAEnter
0xAE菜单间切换（右下 + 左上短按）
0xAF开关屏幕
唤醒逻辑也在这条口上：屏幕处于休眠态时收到任意一帧，固件先恢复亮度、把 time_sync 置位 （触发一次校时），然后再处理该帧——所以按一下键就能点亮并自动校时。
