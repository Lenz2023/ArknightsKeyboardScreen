刷入固件

SKYLOONG GK87 / GK4 键盘副屏 · 明日方舟面板 · ESP32-S3 / 16MB Flash

需要 Chrome / Edge 89+（桌面版）
用 USB 数据线把键盘连到电脑，点上面的按钮 → 选择串口 → 等待烧录完成

当前浏览器不支持 Web Serial。
请换用 Chrome 或 Edge，或看下面的「离线方式」。

烧录步骤

  1. 用能传数据的 USB 线把键盘接到电脑（不是只能充电的线）。
  2. 点上面的 CONNECT，在弹窗里选串口——选哪个见下一节。
  3. 提示「Erase device」时选不要擦除（保留已保存的 WiFi / 账号 / 自定义背景）；只有想恢复出厂才擦。
  4. 等进度条走完（约 1–2 分钟），设备自动重启即完成。

选哪个串口？

ESP32-S3 用原生 USB，插上后会同时出现两个口，名字不一样：

  • 选这个 — 名字里带 USB 串行设备（英文 USB Serial Device）， Windows 形如 USB 串行设备 (COM6)；macOS 是 /dev/cu.usbmodem14101； Linux 是 /dev/ttyACM0。
  • 不要选 — 名字里带 USB JTAG/serial debug unit 的那个口，那是调试用的。
  • 另外还能看到一个不带端口号的 USB Composite Device，它不是串口，选不了。

浏览器弹窗里通常只显示 COM6 这样的短名，看不到中文描述。想确认端口和名字的对应关系， 可以在 Windows 里执行一次 Get-CimInstance Win32_SerialPort | Select-Object DeviceID,Name,PNPDeviceID， 带 VID_303A 的就是这块键盘；或者直接跑 tools\flash-noidf.ps1， 它会打印"系统里的串口"列表并标出准备烧录的那一个。

万一选错了口烧不进去：回到页面再点一次 CONNECT，换另一个 COM 号重试即可，不会刷坏设备。

注意事项

  • 键盘闲置约 10 分钟会自动熄屏休眠，休眠时 USB 会断开——先按一下键唤醒再点烧录。
  • 如果提示端口被占用：关掉串口助手 / idf.py monitor / 其它占用串口的程序。
  • 本页烧的是四个分片镜像（0x0 / 0x8000 / 0x10000 / 0x20000），不会动 NVS，所以设置和自定义背景图都保留。
  • 烧完如果是第一次使用，屏幕会进配网二维码页：用手机连 SKYLOONG 4.0 Screen 热点完成配网。

浏览器不支持 / 想离线烧

仓库里提供了不依赖 ESP-IDF 的脚本，只要有 Python 就行：

  • Windows：tools\flash-noidf.ps1
  • macOS / Linux：tools/flash-noidf.sh

它们会自动装 esptool，再把 docs/flasher/firmware/ 里的四个镜像写到各自偏移。 完整说明见 烧录指南。
